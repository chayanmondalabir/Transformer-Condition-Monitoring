# Transformer-Condition-Monitoring
ML/DL pipelines for transformer condition monitoring via infrared thermography. Implements SVM, KNN, DT, LR, LS-SVM and CNN transfer-learning models (InceptionV3, MobileNetV2, DenseNet121, proposed Modified VGG-16) to classify transformers as healthy or defective. Modified VGG-16 achieves 99% accuracy.
